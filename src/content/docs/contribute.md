This guide is an Astro [Starlight](https://starlight.astro.build) site in a [git repository](https://github.com/anaxite/technical-writers-guide-to-ai). Do you have something you want to add? Get in touch!

This guide welcomes contributions of any size and contributors of any skill level.

## Contribution types

### 1. Submit an issue

Did you notice an error, have a question, or want to propose a change?
Submit a GitHub issue from the repository page.

### 2. Submit edits

If you want to make a direct correction or improvement, you can submit your changes as a GitHub pull request.

1. On GitHub, fork the repository to your own account.
2. Make your changes in the fork.
3. Submit the changes as a pull request for review.

## Durability and perishability

The world of generative AI changes quickly. When writing content, consider whether your content is more durable or more perishable:

- *Durable* content usually relates to how generative AI systems work, their failure modes, and principles that don't change much when new models get released.
- *Perishable* content relates to things like tool names, model names, specific model behavior, prices, screenshots, prompts, or benchmarks. This kind of content may change every few months.

If you write perishable content, make sure you date your submission.

## Questions and contradictions

This guide is not a how-to; a page or section can be about discussing a question or problem, whether or not there's a good answer. There may also be contradictory answers! This is normal. 

When adding discussion sections, ask yourself whether they add useful information. Do they help the reader learn and think? Does the reader leave with better understanding? Discussions that help the reader are the most useful discussions to add.
